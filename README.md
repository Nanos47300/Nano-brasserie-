# Nano Brasseur

Dépôt de travail de la Nano Brewery d’Arnaud.

## Organisation

- `base_de_verite/` : règles, préférences, matériel, eau, stocks, levures et houblon maison.
- `recettes/ipa/` : recettes IPA et leurs versions.
- `recettes/stout/` : recettes Extra Stout et leurs versions.
- `recettes/autres/` : autres styles.
- `brassins/` : fiches réelles B001, B002, etc.
- `archives/` : documents remplacés ou retirés du travail actif.

## Règle de fonctionnement

Le dossier `base_de_verite` contient les informations propres à la Nano Brewery. Une donnée inconnue ne doit jamais être inventée. Les fichiers téléversés dans l’agent Nano Brasseur sont une copie de cette base et doivent être remplacés après chaque mise à jour validée.

## Agent

Nom : **Nano Brasseur**

La recherche Internet peut compléter les connaissances techniques, mais elle ne doit jamais remplacer silencieusement une donnée validée ou mesurée contenue dans la base de vérité.
